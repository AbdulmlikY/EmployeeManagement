# Employee Management System - Java Swing

This is an Employee Management System developed in Java using Swing.  
It was created as a basic assignment for the **Visual Programming** course.

## Features
1. **Add Employee**: 
   - Input employee details: ID, Name, Department, Salary.
   - Save employee details to a text file.
   
2. **Search Employee**:
   - Search an employee by ID.
   - Display employee details if found, or show "Employee not found."

## File Handling
- Employee records are saved in a text file (`employees.txt`).
- Data is stored and retrieved in a CSV format.

## Notes
- Built with Java Swing.
- Uses `JTextField`, `JTextArea`, `JButton`, and `JFileChooser`.
- Handles file I/O exceptions gracefully with error messages.
